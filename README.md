# Moved: Ada Agent Skills

This repo is archived. Its skills now live in one plugin that works over
adacli or the Ada MCP: **[roystonlee-ada/ada-agent-skills](https://github.com/roystonlee-ada/ada-agent-skills)**.

Move over:

```bash
claude plugin uninstall ada-architect-skills-mcp@ada-architect-mcp
claude plugin marketplace add roystonlee-ada/ada-agent-skills
claude plugin install ada-agent-skills@ada-agent-skills
```

Codex: `codex plugin marketplace add roystonlee-ada/ada-agent-skills`, then
`codex plugin add ada-agent-skills@ada-agent-skills`.
